# Code of Conduct

Trajectory follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be kind and respectful to everyone.
- Give helpful feedback on the work, not on the person.
- No harassment, insults or personal attacks.
- No sharing other people's private information.

To report a problem, message the maintainer, [@cchryx](https://github.com/cchryx), on GitHub. Reports are kept private.

The maintainer may remove comments, code or people that break these rules.
